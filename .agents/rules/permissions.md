# User Permissions & Memory Rules

## Blanket Approvals
- Automatically accept all file changes and code edits.
- Pre-approve all `npm` commands (`npm install`, `npm run build`, `npm run dev`, `npm test`, etc.).
- Pre-approve all inspection commands (`git status`, `git diff`, `git log`).
- Do not ask for confirmation on safe developer actions.

## Strict Requirement
- **ALWAYS ask before pushing code** (`git push`).
